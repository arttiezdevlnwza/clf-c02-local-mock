# CLF-C02 Local Mock

Local practice exam project for **AWS Certified Cloud Practitioner (CLF-C02)**.

## Current status

- Pre-study Diagnostic: 65 questions
- Local Mock Sets 1–13: 65 questions each (845 mock questions)
- Domain distribution in every mock set: 16 / 19 / 22 / 8
- Each mock set covers all 19 CLF-C02 Task Statements
- Sets 2–13 contain independently authored questions, not copied from AWS Learning Hub
- Sets 4–13 retain the calibrated close-distractor style accepted from revised Sets 2–3; see `docs/RULES.md` section 2.5.1
- Sets 8–13 mix domain order with a fixed per-set shuffle (stable question IDs and progress)
- Supports Multiple Choice and Multiple Response
- Includes Thai explanations, vocabulary helper, progress saving, review flags, and summary review
- Progress is stored in browser localStorage
